# ARTIFACT: Process: cmd.exe -> curl.exe -> downloaded child process chain.
# ARTIFACT: File: %TEMP%\<OUTPUT_NAME> written by curl.exe.
# ARTIFACT: Network: HTTP GET to STAGING_HOST with curl's default
#   User-Agent (curl/x.y.z) — distinctive vs browser traffic.
# ARTIFACT: Registry: RunMRU value contains the full command string.
# ARTIFACT: Prefetch: CURL-EXE prefetch record if prefetch enabled.
# ARTIFACT: Zone.Identifier ADS on the downloaded file if the server supplies
